# بوت الأذكار التلقائي

بوت تلغرام يرسل الأذكار (نص + صورة) تلقائيًا لكل المشتركين في أوقات تحددها أنت.

## 1) إنشاء البوت في تلغرام
1. افتح محادثة **BotFather** في تلغرام.
2. أرسل `/newbot` واتبع التعليمات.
3. احفظ الـ **Token** الذي يعطيك إياه (شكله: `123456:ABC-xyz...`).

## 2) تجهيز الأذكار
- عدّل ملف `config.json`:
  - `time`: الوقت بصيغة 24 ساعة "HH:MM" (مثلاً "05:00").
  - `text`: نص الذكر.
  - `image`: مسار الصورة داخل مجلد `images/` (اختياري، احذف السطر إن لم ترد صورة).
  - `timezone`: المنطقة الزمنية (افتراضيًا "Asia/Riyadh").
- ضع صور الأذكار داخل مجلد `images/` بنفس الأسماء المذكورة في config.json.
- يمكنك إضافة أي عدد من الأوقات، فقط أضف عنصرًا جديدًا داخل قائمة `schedule`.

## 3) النشر على Render (مجانًا)
1. أنشئ مستودع GitHub وارفع هذه الملفات إليه.
2. من لوحة Render: **New > Web Service** واربطه بالمستودع.
3. اختر:
   - **Environment**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python main.py`
4. من تبويب **Environment**، أضف متغير بيئة:
   - `BOT_TOKEN` = التوكن الذي حصلت عليه من BotFather
5. اضغط Deploy. بعد نجاح النشر سيظهر رابط للخدمة (مثل `https://xxx.onrender.com`).

### ⚠️ ملاحظة مهمة عن النوم التلقائي (Sleep)
الخطة المجانية في Render تُدخل الخدمة في وضع سكون بعد ~15 دقيقة من عدم الاستخدام،
مما قد يعطّل الإرسال المجدول أثناء السكون. الحل:
- استخدم خدمة مجانية مثل **UptimeRobot** أو **cron-job.org** لإرسال طلب (ping)
  إلى رابط خدمتك (`https://xxx.onrender.com`) كل 5 دقائق، ليبقى البوت مستيقظًا دائمًا.

## 4) أوامر البوت للمستخدمين
- `/start` — الاشتراك في الأذكار التلقائية
- `/stop` — إلغاء الاشتراك
- `/test` — معاينة أول ذكر في الجدول (لك أنت فقط، للتجربة)
- `/stats` — عدد المشتركين (يظهر فقط إذا كنت أنت الأدمن المحدد في config.json عبر admin_chat_id)

## 5) التجربة محليًا قبل النشر (اختياري)
```bash
pip install -r requirements.txt
export BOT_TOKEN="التوكن_هنا"
python bot.py
```

## ملاحظة عن قاعدة البيانات
المشتركون يُحفظون في ملف `subscribers.db` (SQLite). هذا الملف يبقى محفوظًا
أثناء عمل الخدمة، لكنه قد يُمسح عند عمل **نشر جديد (redeploy)** على Render
المجاني لأن التخزين غير دائم. إذا أردت حفظًا دائمًا 100% عبر عمليات النشر
المتكررة، يفضل لاحقًا استخدام قاعدة بيانات PostgreSQL المجانية من Render
بدلاً من SQLite — أخبرني إن رغبت أساعدك بهذا التحويل.
